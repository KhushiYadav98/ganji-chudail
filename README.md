# Ganji Chudail 👻✂️

A mobile-first browser game: survive **60 seconds** in a purani haveli while Ganji Chudail chases you with her kainchi. If she catches you, she cuts all your hair!

## How to play
- **Move:** drag your thumb anywhere on screen (WASD / arrow keys on PC)
- **DAUD! (sprint):** hold the button (Shift / Space on PC) – burns stamina fast
- **Stamina** drains every second – at zero you can barely move
- **Stress hair:** you shed hair chunks while running, faster when she's close
- **Grab hair chunks** for +stamina… but she eats them too to refuel (and stops briefly to munch)
- **Red eyes + scream = lunge** – dodge sideways!
- Survive 60s with as much hair as possible ⭐⭐⭐

Customize your hero (skin, hair style, hair colour, shirt, pants, name) before each run.

## Run it
It's a single file – just open `index.html` in any browser, or host it on GitHub Pages.
